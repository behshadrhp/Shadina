# شادینا — مستندات فارسی

این مجموعه مستندات **پیاده‌سازی تأییدشده** مخزن شادینا را در commit `6c14149` (`:zap: add: Authorization Layer`)
توصیف می‌کند که در **۲۰۲۶-۱۰-۲۹** بررسی شده است. مستندات از کد منبع، مهاجرت‌های SQL، فایل‌های پیکربندی و
بررسی‌های زمان اجرای فقط-خواندنی روی دیتابیس توسعه محلی نوشته شده‌اند. ویژگی‌هایی که پیاده‌سازی نشده‌اند
توصیف نمی‌شوند.

## قراردادهای وضعیت مستندات

| وضعیت | معنا |
|---|---|
| **کامل** | همه شواهد پیاده‌سازی برای آن حوزه بررسی و مستند شده است؛ شکاف‌های شناخته‌شده صریحاً فهرست شده‌اند. |
| **جزئی** | حوزه مستند شده اما برخی رفتارها قابل تأیید نبودند یا کد و قرارداد اختلاف دارند. |
| **پیاده‌سازی نشده** | ویژگی در مخزن وجود ندارد. |
| **تأیید نشده** | کد یا پیکربندی وجود دارد اما در این بررسی اجرا نشده است. |
| **مسدود** | تأیید به‌دلیل نبود ابزار، اعتبارنامه یا محیط ممکن نشد. |

## فایل‌های منبع حقیقت

هرجا این مستندات و کد اختلاف دارند، کد برنده است. مهم‌ترین فایل‌ها:

- نقطه ورود: `cmd/api/main.go`
- روتر: `cmd/api/router.go`
- میان‌افزار: `cmd/api/middleware.go`
- هندلرها: `cmd/api/*.go`
- احراز هویت: `internal/auth/*.go`
- Storage و SQL: `internal/storage/*.go`
- راه‌اندازی دیتابیس: `internal/db/*.go`
- مهاجرت‌ها: `cmd/migrate/migrations/*.sql`
- Seed: `cmd/seed/main.go`، `internal/db/seed.go`
- پیکربندی: `internal/env/env.go`، `.example.env`، `docker-compose.yaml`، `makefile`
- قرارداد API: حاشیه‌نویسی‌های هندلر و `docs/`
