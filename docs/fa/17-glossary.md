# 17. واژه‌نامه

اصطلاحات به انگلیسی فهرست شده‌اند و معادل فارسی استفاده‌شده در مستندات فارسی کنار آن آمده است. نام بسته‌ها،
انواع، توابع و متغیرهای محیطی به شکل اصلی باقی می‌مانند.

| اصطلاح | فارسی | تعریف |
|---|---|---|
| API | رابط برنامه‌نویسی کاربردی | رابط HTTP/JSON ارائه‌شده توسط `cmd/api`. |
| Handler | هندلر | یک `http.HandlerFunc` در `cmd/api` که یک endpoint را پیاده‌سازی می‌کند. |
| Middleware | میان‌افزار | پوششی حول هندلرها؛ شادینا از لاگ درخواست، احراز هویت JWT و بررسی مالکیت پست استفاده می‌کند. |
| Router | مسیریاب | روتر chi در `cmd/api/router.go` که متد/مسیر را به هندلر نگاشت می‌کند. |
| DTO | شیء انتقال داده | ساختارهای payload درخواست در `internal/dto`. شادینا برای پاسخ‌ها از DTO استفاده نمی‌کند. |
| Storage | لایه ذخیره‌سازی | `internal/storage`؛ متدهای SQL و ساختارهای ماندگاری. |
| Repository | مخزن | انتزاع ماندگاری. شادینا نمای `Storage` دارد، نه repository به‌ازای هر موجودیت. |
| Service layer | لایه سرویس | لایه منطق کسب‌وکار. **وجود ندارد**؛ هندلرها مستقیماً storage را صدا می‌زنند. |
| Dependency Injection | تزریق وابستگی | ساخت/سیم‌کشی دستی در `cmd/api/main.go`. |
| Monolith | یکپارچه | یک فرآیند API قابل استقرار که همه منطق بک‌اند را دارد. |
| Layered architecture | معماری لایه‌ای | انتقال → هندلرها → storage → DB، با بسته‌های پشتیبان. |
| Migration | مهاجرت پایگاه داده | تغییرات SQL نسخه‌بندی‌شده در `cmd/migrate/migrations` که با golang-migrate اعمال می‌شوند. |
| Seed | داده اولیه | تولید fixture توسعه در `internal/db/seed.go` / `cmd/seed`. |
| Schema | طرح‌واره | تعریف جدول/ستون/محدودیت PostgreSQL. |
| ERD | نمودار موجودیت-رابطه | Entity Relationship Diagram؛ به `diagrams/database-erd.mmd` مراجعه کنید. |
| Primary Key (PK) | کلید اصلی | شناسه یکتای سطر؛ مثلاً `users.id`، مرکب `followers(user_id, follower_id)`. |
| Foreign Key (FK) | کلید خارجی | محدودیت ارجاعی بین جدول‌ها. |
| Unique Constraint | محدودیت یکتایی | از مقادیر تکراری جلوگیری می‌کند؛ مثلاً `users.email`. |
| Index | ایندکس | ساختار B-tree/GIN برای تسریع جست‌وجو؛ به `000007_add_indexes` مراجعه کنید. |
| GIN | جین | ایندکس معکوس PostgreSQL، استفاده‌شده برای ایندکس‌های trigram/آرایه. |
| Trigram (`pg_trgm`) | تری‌گرام | افزونه‌ای که از ایندکس‌های `ILIKE '%...%'` پشتیبانی می‌کند. |
| `citext` | سایتی‌اکست | نوع متن حساس‌نبودن به حروف برای ایمیل. |
| Transaction | تراکنش | واحد اتمی کار DB. seed یکی تلاش می‌کند اما درست استفاده نمی‌کند؛ هندلرهای درخواست هیچ ندارند. |
| Isolation level | سطح جداسازی | جداسازی تراکنش PostgreSQL؛ صریحاً پیکربندی نشده. |
| Connection pool | استخر اتصال | pool `database/sql` با max open/idle و زمان بیکاری. |
| N+1 query | کوئری N+1 | یک کوئری به‌ازای هر سطر والد؛ `GET /v1/posts` نظرها را برای هر پست بارگذاری می‌کند. |
| Full table scan | اسکن کامل جدول | خواندن همه سطرها؛ برای جست‌وجوی محتوا/ترتیب فید بدون ایندکس ممکن است. |
| Soft delete | حذف نرم | علامت‌گذاری سطرها به‌جای حذف. **پیاده‌سازی نشده**. |
| JWT | توکن وب JSON | توکن امضاشده برای احراز هویت. |
| Claim | ادعا | فیلد JWT مانند `sub`، `exp`، `iss`، `aud`. |
| `sub` | شناسه موضوع | claim موضوع؛ شادینا شناسه کاربر را ذخیره می‌کند. |
| Issuer (`iss`) | صادرکننده | صادرکننده توکن؛ `Shadina`. |
| Audience (`aud`) | مخاطب | مخاطب موردنظر توکن؛ `Shadina`. |
| HS256 | اچ‌اس-۲۵۶ | الگوریتم امضای JWT با HMAC-SHA256. |
| Bearer token | توکن حامل | طرح `Authorization: Bearer <jwt>`. |
| Refresh token | توکن تازه‌سازی | توکن طولانی‌عمر برای دریافت توکن دسترسی جدید. **پیاده‌سازی نشده**. |
| Revocation | ابطال | بی‌اعتبار کردن توکن‌های صادرشده. **پیاده‌سازی نشده**. |
| bcrypt | بی‌کریپت | تابع هش رمز؛ `DefaultCost` استفاده می‌شود. |
| Authentication | احراز هویت | اثبات هویت (ورود/اعتبارسنجی توکن). |
| Authorization | مجوزدهی | تصمیم درباره اینکه کاربر احراز هویت‌شده چه کاری می‌تواند بکند (نقش/مالکیت). |
| Role | نقش | `user`، `moderator`، `admin` در `roles` seed شده‌اند. |
| Ownership check | بررسی مالکیت | `UserPostAccessMiddleware` مقدار `user.ID` را با `post.UserID` مقایسه می‌کند. |
| 401 Unauthorized | ۴۰۱ | احراز هویت غایب/نامعتبر (یا به‌اشتباه، برخی توکن‌های بدشکل). |
| 403 Forbidden | ۴۰۳ | احراز هویت‌شده اما مجاز نیست؛ شادینا به‌جای آن 401 استفاده می‌کند. |
| 404 Not Found | ۴۰۴ | منبع غایب؛ برای کاربران ناسازگار استفاده می‌شود. |
| 500 Internal Server Error | ۵۰۰ | خطاهای سرور/storage/JWT؛ گاهی برای خطاهای ورودی کلاینت استفاده می‌شود. |
| Error envelope | پوشش خطا | پاسخ `{success, message, internal_code, data}`. |
| Internal code | کد داخلی | کد مختص برنامه (مثلاً 4017)، نه وضعیت HTTP. |
| Correlation ID | شناسه همبستگی | شناسه درخواست برای ردیابی. **پیاده‌سازی نشده**. |
| Request ID | شناسه درخواست | همان مفهوم؛ پیاده‌سازی نشده. |
| Observability | قابلیت مشاهده | لاگ، متریک، ردیابی، سلامت. فقط لاگ‌نویسی جزئی وجود دارد. |
| Metrics | معیارها | تله‌متری عددی (تأخیر، خطاها). **پیاده‌سازی نشده**. |
| Tracing | رهگیری | ردیابی توزیع‌شده درخواست. **پیاده‌سازی نشده**. |
| Liveness | زنده‌بودن | آیا فرآیند در حال اجراست؟ `/v1/health` استاتیک است. |
| Readiness | آمادگی | آیا فرآیند می‌تواند به وابستگی‌ها سرویس دهد؟ پیاده‌سازی نشده. |
| Heartbeat | ضربان | میان‌افزار `/ping` که `.` برمی‌گرداند. |
| Swagger / OpenAPI | سواگر / اوپن‌ای‌پی‌آی | قرارداد و UI API. فایل‌های Swagger 2.0 کهنه‌اند. |
| CORS | سی‌اوآر‌اس | Cross-Origin Resource Sharing؛ پیکربندی نشده. |
| TLS | تی‌ال‌اس | رمزنگاری انتقال؛ در برنامه پیکربندی نشده. |
| Graceful shutdown | خاموشی تدریجی | تخلیه درخواست‌های در جریان؛ پیاده‌سازی نشده. |
| Rate limiting | محدودیت نرخ | محدودسازی درخواست‌ها؛ پیاده‌سازی نشده. |
| IDOR | دسترسی مستقیم به شناسه شیء | دسترسی به شیء کاربر دیگر با شناسه؛ مرتبط با دسترسی فید. |
| SQL injection | تزریق SQL | تزریق SQL از طریق ورودی؛ کوئری‌ها پارامتری‌اند. |
| Parameterized query | کوئری پارامتری | جانشین‌های `$1`؛ در همه‌جا استفاده می‌شود. |
| Prepared statement | دستور آماده | دستور پارامتری قابل استفاده مجدد؛ `database/sql` اجرا را مدیریت می‌کند. |
| `database/sql` | پکیج دیتابیس | انتزاع استاندارد DB در Go. |
| `lib/pq` | کتابخانه پی‌کیو | درایور PostgreSQL. |
| `sql.ErrNoRows` | خطای بدون ردیف | سطری یافت نشد؛ در برخی storeها به `consts.NOT_FOUND` نگاشت می‌شود. |
| Sentinel error | خطای نشانه | مقدار خطای سطح بسته مانند `consts.NOT_FOUND`. |
| Rollback | بازگردانی | برگشت مهاجرت/تراکنش؛ هشدارهای مخرب را ببینید. |
| Dirty migration | مهاجرت ناسالم | وضعیت golang-migrate پس از مهاجرت شکست‌خورده. |
| Idempotent | خودتکرارپذیر | اجرای مکرر ایمن است؛ seed **idempotent نیست**. |
| `.env` | فایل محیطی | فایل محیط محلی که godotenv بارگذاری می‌کند. |
| Environment variable | متغیر محیطی | پیکربندی سطح فرآیند. |
| Secret | راز | مقدار حساس مانند راز JWT/رمز DB. commit نکنید. |
| DSN | رشته اتصال داده | رشته اتصال دیتابیس. |
| Connection string | رشته اتصال | همان DSN. |
| Development environment | محیط توسعه | راه‌اندازی محلی توصیف‌شده در راهنمای توسعه. |
| Production environment | محیط عملیاتی | استقرار واقعی؛ توسط مخزن ارائه نشده. |
| Docker Compose | داکر کامپوز | ارکستراسیون کانتینر محلی؛ اینجا فقط PostgreSQL. |
| Volume | والیوم | ذخیره‌سازی پایدار Docker برای PostgreSQL. |
| Container | کانتینر | واحد زمان اجرای جداشده. |
| Migration CLI | ابزار مهاجرت | باینری خارجی `migrate`. |
| Swag | سواگ | تولیدکننده Swagger؛ تولید اکنون شکست می‌خورد. |
